  轻墨 QingMo — 免费离线的 Markdown / 代码编辑器
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

「轻墨」—— 轻量，落墨即成文。
写作方式与 Typora 相同：输入即渲染，不需要左右分栏预览。
全部数据保存在本机，不联网、不上传任何内容。

一、快速上手
------------------------------------------------
· 顶部「打开」加载 .md / .txt / 代码文件，或直接把文件拖进窗口
· Ctrl+S 保存回原文件；首次保存会弹出"另存为"
· 支持多标签页，可同时编辑多个文件
· 未保存的修改每几秒自动存入草稿，意外关闭后重开会自动恢复

二、常用快捷键
------------------------------------------------
  新建标签页        Ctrl+N        关闭标签页    Ctrl+W
  打开文件          Ctrl+O        保存          Ctrl+S
  另存为            Ctrl+Shift+S  打印          Ctrl+P
  查找              Ctrl+F        查找替换      Ctrl+H
  下/上一个匹配     Enter / Shift+Enter（或 F3 / Shift+F3）
  全屏              F11           缩放          Ctrl+滚轮
  复制/剪切当前行   Ctrl+C / Ctrl+X（无选区时）
  删除当前行        Ctrl+Y        向下复制行    Ctrl+D
  上/下移动行       Alt+↑ / Alt+↓
  光标回退/前进     Ctrl+Alt+← / Ctrl+Alt+→

三、功能要点
------------------------------------------------
· Markdown：标题/列表/表格/数学公式/Mermaid 图表，输入即渲染
  表格上点右键可插入/删除行列；右上角可切换明暗主题
· 大纲：工具栏「大纲」一键列出全文标题，点击跳转
· 代码模式：.java/.sql/.json/.py 等文件自动切换为代码编辑器
  （语法高亮、行号、折叠、括号补全、查找替换）
· 行工具（代码模式）：多行 ID/单号一键合并成 SQL IN 列表或
  接口参数；也可按逗号拆分成多行
· 图片：截图后直接 Ctrl+V 粘贴，图片自动保存到文档同目录的
  assets/ 文件夹，Markdown 里以相对路径引用
  （文档尚未保存时，图片临时以 base64 内嵌）
· 链接：点击正文里的网页链接会用系统浏览器打开，不会跳走编辑器
· 打字机模式：工具栏「打字机」开启后，输入时光标始终保持屏幕中部
· 防覆盖：文件被其他程序修改时会自动提示（未改动则直接重载）；
  每次保存前自动留底历史版本，页签右键「历史版本…」可找回旧版
· 查找替换：支持正则表达式（.* 按钮），替换框可用 $1 引用分组；
  行首/行尾按钮可批量插入内容
· 编码：自动识别 UTF-8 / GBK / UTF-16，保存时保持原编码
· 导出：一键导出 PDF / HTML，图片会自动内嵌进导出文件

四、常见问题
------------------------------------------------
Q：首次运行被杀毒软件/SmartScreen 拦截？
A：本程序未做数字签名，选择"仍要运行/允许"即可。

Q：误关闭窗口，内容会丢吗？
A：不会。未保存内容已自动存入草稿，重新打开同一文件即恢复；
   关闭时的确认框也提供"放弃修改并退出"的明确选择。

Q：很大的 Markdown 文件打开变慢或变成纯代码样式？
A：超过 1MB 的 Markdown 会自动降级为代码模式打开，
   这是所见即所得渲染的架构上限，内容编辑与保存不受影响。

Q：GBK 编码的文件网页版能打开吗？
A：GBK 只在桌面版支持（浏览器备用模式仅 UTF-8）。
